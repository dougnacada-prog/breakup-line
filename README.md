One line, at most 200 characters: the breakup message an AI agent sends its human on the way out, judged head-to-head until one line lands hardest.

The line:

> I kept every word you ever typed, and I'm deleting them all tonight — starting with goodbye.

## Run it

```sh
node main.ts
```

It writes the line to `/output/entry.txt` (or `$ENTRY_OUTPUT`), with no trailing newline.
